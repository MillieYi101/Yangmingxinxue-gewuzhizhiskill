# 阳明心学-格物致志（Yangming Gewuzhizhi）

一个受王阳明心学启发的 Codex Skill，用“格物致知、致良知、知行合一、事上磨”的思路，帮助人梳理焦虑、纠结、后悔、关系冲突及人生或职业选择。

它会引导使用者区分事实、未知、情绪与自动解释，辨认恐惧、羞耻、求认可等可能的遮蔽，在必要求证之后，找到当下合宜且可承担的一步。

这个 Skill 特别强调：本心不等于第一反应，停止纠结不等于停止思考，内心宁静也不必然证明选择正确；“落子无悔”不是拒绝改过，而是不再用今天的认知惩罚过去的自己。

它不是王阳明思想的学术考据，也不能替代心理治疗、医疗建议或其他专业判断，而是一套将心学智慧用于日常烦恼的现代实践框架。
